# FCM更新則の式変形と安定性

## 同じ更新をどう計算するか

二乗ユークリッド距離を q_ik = ||x_i − c_k||²、α = 1/(m−1) とすると、通常のFCM更新は

u_ik = q_ik^(−α) / Σ_j q_ij^(−α)

です。これは厳密に

u_i = softmax_k(−log(q_ik)/(m−1))

と同じです。logsumexpを使うなら、z_ik = −log(q_ik)/(m−1) として

log(u_ik) = z_ik − logsumexp_j(z_ij)

になります。qは二乗距離なので、ユークリッド距離dを使う式の指数 −2/(m−1) と混同しません。

## 実装中の通常経路

r_i = min_j q_ij として

w_ik = (r_i/q_ik)^α、u_ik = w_ik / Σ_j w_ij

を用います。全wは[0,1]内で、少なくとも最小距離のwは1になります。正の非常に大きな指数へのexpや、巨大な逆数を作らずに済みます。これはsoftmaxの最大値を引く安定化を、log/expを常時計算しない形で表したものです。

- m=2ではα=1となり、w=r/qだけで済みます
- 距離比を全クラスタ対で作るO(NK²)式は使いません。標準の逆べき正規化はO(NK)です
- 距離計算は二乗距離のままで、sqrtを取りません
- BLAS展開 q=||x||²+||c||²−2x·c でも ||x||² は必要です。hard k-meansのargminと違い、FCMの比率では省けません

## exp/log系関数を使うべき場所

### 1. ratioが先にunderflowする場合

q_min/qが0へunderflowしても、その比の小さなべき乗は表現可能なことがあります。例としてq=[1e−300,1e300], m=1000のmembershipは約[0.79946,0.20054]で、[1,0]ではありません。この条件だけ

exp((log(q_min)−log(q))/(m−1))

へ切り替えます。

### 2. m≈1かつ距離がほぼ等しい場合: log1p

巨大／微小なqで log(q)−log(q_min) を取ると、元の値の小さな相対差が失われます。q_min/qの除算丸めも、1/(m−1)が巨大だと増幅します。

近接する距離では

log(q/q_min) = log1p((q−q_min)/q_min)

を使います。qとq_minが近いときの差の計算とlog1pが、ほぼ1の比率の情報を保持します。m−1<1e−4の通常inverse-power経路に限定してこの保護を入れました。追試用log-domain経路では近接距離に常に適用しています。

テストには q=[1e300,nextafter(1e300,+∞)]、m=nextafter(1,2) を含め、Decimal高精度計算を独立オラクルとしました。単純なlog(q)からのsoftmaxではこの差を落とします。

### 3. 目的関数の極小項: logsumexp / logaddexp

目的関数J=Σ u^m qでは、u^mが先にunderflowしても大きなqとの積は表現可能な場合があります。さらに各項が個別には表現不能でも、総和は表現可能な場合があります。

このため小さな重みの項は m·log(u)+log(q) として保持し、logsumexpで集約してからexpを取ります。チャンクを跨ぐ集約にはlogaddexpを使います。通常のm=2の非極小項は通常の積和計算のままです。

### 4. expm1について

expm1はexp(z)−1をz≈0で正確に求める関数です。現在のFCM正規化にはこの差の形がなく、無理に導入する利点はありません。exp/log系関数を一律に使えば速く／安定になるわけではなく、計算する量と桁落ち箇所に応じて選びます。

## ゼロ距離

q=0ではlog(q)が定義できません。ゼロ距離の中心が複数あれば、それらだけに等分し、他を0にします。epsを一律に加えると別の更新則になるため、明示的に処理します。

## 実測比較

`benchmarks/ablation.py`は、membership kernel単体と同じSciPy fitドライバでのend-to-endの両方を比較します。逆べき、log1p付きlog-softmax、logsumexp正規化、SciPy softmax、単純log-softmaxを同じ距離／初期membershipで測ります。

追試では理論的に同値であることと高速であることを分けます。常時log/expの経路が遅い場合も、極端条件での正確性の保護としては有用です。[性能要約](../docs/PERFORMANCE_JA.md)を参照してください。実験ログは同梱せず、スクリプト実行時に新しく生成します。
