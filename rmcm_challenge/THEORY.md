# RMCM の式と前計算

## 固定近傍の定義

入力は X ∈ R^(N×D)。近傍 `Nδ(i)={j : ||xi−xj||₂≤δ}` は自分自身を含む。隣接行列 A の各行和を di として、`Pij=Aij/di` とする。P は行確率行列であり、A が対称でも、次数が違えば P は一般には対称ではない。

初期中心は異なるデータ行番号を K 個サンプリングする。反復では、暫定最近傍割り当てを z、one-hot 行列を H とする。

- `zi = argmin_c ||xi−vc||₂²`（同距離なら最小 c）
- `Ric = #{j∈Nδ(i):zj=c}/di`
- `vc = Σi Ric xi / Σi Ric`

R に指数はかけない。この RMCM は目的関数最小化に基づく方法ではなく、収束保証はない。目的関数に基づく RMCM2 とは区別する。ここでは RMCM2 の式を推測して追加しない。

## 実数上で厳密に同じ前計算

`R=PH` だから、

- `RᵀX = Hᵀ(PᵀX)`
- `Rᵀ1 = Hᵀ(Pᵀ1)`

最初に `Y=PᵀX`、`s=Pᵀ1` を作れば、反復ごとの中心更新はラベル別に Y と s を加算すればよい。P を前計算してよい理由は、ユーザー指定の δ 関係が中心に依存せず、最初に一度だけ構築されるため。

転置を落とした `PX` は一般には誤り。独立に確認した例 `X=[0,1,3]`, `δ=2`, `z=[0,0,1]` は次数 `[2,3,2]`、`Y=[1/3,11/6,11/6]`、`s=[5/6,4/3,5/6]`、更新中心 `[1,11/5]` になる。

これは目的関数を変更した近似ではなく、指定された中心更新の計算順序の変更。ただし浮動小数点の和の順番は異なり、ビット一致・境界ラベル一致の一般保証にはならない。

## 計算量

E は自己辺を含む有向辺数。近傍構築には cKDTree を用いるが、次元・分布・δ により効果が変わり、最悪計算量を一律に N log N と主張しない。密な関係は E=N² になる。

| 処理 | 時間の主項 | 補足 |
|---|---|---|
| 暫定最近傍割り当て（共通） | O(NKD) | 一時配列をブロック化 |
| NumPy R 生成 | O(E+NK) | 辺を一度数える。クラスタごとの近傍再走査はしない |
| NumPy 密 R の中心更新 | O(NKD) | BLAS による RᵀX |
| CSR PH と中心更新 | 概ね O(E+nnz(R)D) | 中間 R は疎 |
| Adjoint の一度だけの前計算 | O(ED) | Y と s |
| Adjoint の反復中心更新 | O(ND+KD) | R を作らない |
| 最終密 R の返却 | O(E+NK) 程度 | 中間疎積を含む。出力自体に NK 要素 |

Adjoint の追加保存領域は Y が ND、s が N。グラフは O(E+N)。NumPy 基準は行番号配列 O(E) と密 R を保持する。完全状態履歴は最大 `cycle_window×(N+KD)` 要素相当と辞書・バイト列のオーバーヘッドを持つ。

全点近傍の場合は `Ric=n_c/N` なので、占有中心はすべて全体平均になる。この簡約を全バックエンド共通で使い、不要な Y/s は作らない。最終 R は占有率の独立した密配列コピーを返す。

## 停止・返却契約

1 回のステップは `(旧中心) → z → R → 新中心`。
返却値は最後の `z, R, 新中心`。追加再割り当てをしないので、各非空中心は返却 R の重み付き平均である（有限精度内）。停止は完全状態の一致で判断する。ラベルだけの再登場を周期と誤判定しない。

独立した有理数演算の例として、X=`[[-1,-3],[5,-3],[3,4],[-1,-2],[1,-3],[2,2]]`, δ=`7.3`, 初期中心=`[[1,-3],[2,2]]` は空クラスタなしで周期 2 を持つ。これは RMCM の性質であり、実装の欠陥や丸め誤差による偽の収束ではない。

`fixed_point` は実装の浮動小数点写像の連続完全状態一致を意味する。一般の実数 RMCM の全入力に対する収束を証明したものではない。

## δ 境界と数値の扱い

cKDTree は少し広げた半径で候補だけを取り、最終的に直接差分の `sqrt(einsum(diff,diff)) <= δ` で判定する。近傍の δ 自体を緩めない。自己辺と対称性をテストし、境界のちょうど値・1 ULP 前後を直接全探索の小規模オラクルと照合する。δ=0 は値の等値で判断する。

通常の float64 距離を安全に扱えない極端な大きさは明示的に拒否する。非常に小さな差が平方時に 0 または subnormal になった場合も、誤った同距離に変えず再スケーリングを求める。最近傍判定では cancellation を起こし得る Gram 展開 `||x||²+||v||²−2x·v` を使わない。

## 実際に確認した軌道不一致の境界例

`benchmarks/roundoff.py` は、単なる注意書きではなく、実際に不一致を起こした小さい入力を再現し、結果を JSON に保存する。

X=`[[1,-1],[4,5],[-3,-4],[1,3],[-5,3],[2,2],[-2,-2],[100,100]]`、δ=`12`、初期中心は行番号 `[0,1,7]`。最初の 7 点が完全な近傍成分で、最後の点は孤立する。数学的には最初の 2 中心が同じ平均に重なるが、約 10^-16 の丸め差で暫定ラベルが変わる。この環境では NumPy が 3 反復で固定点、CSR と adjoint が 4 反復で周期を検出した。

全関係が完全グラフの場合の共通簡約では、この部分グラフの退化までは解消しない。任意の許容誤差で「同距離」とみなす変更は、指定アルゴリズムの最近傍規則を変えるため導入していない。通常実測の一致結果から、こうした入力にも普遍的に軌道が一致すると推論しない。
